# WB Price Tracker

[![CI](https://github.com/d3c0r1x/wb-price-tracker/actions/workflows/ci.yml/badge.svg)](https://github.com/d3c0r1x/wb-price-tracker/actions/workflows/ci.yml)

Telegram-бот для мониторинга цен и остатков на Wildberries. При отправке артикула бот сохраняет товар в базу данных, ежедневно проверяет цену и остатки и уведомляет пользователя о снижении цены или исчерпании товара.

Проект реализован по учебному техническому заданию («трекер цен с push-уведомлением раз в сутки»). В процессе разработки выявлены ограничения публичного API Wildberries, связанные с защитой от автоматизированных запросов; подробности приведены ниже.

## Команды

| Команда | Назначение |
|---|---|
| `/track 12345678` | начать отслеживание товара по артикулу |
| `/untrack 12345678` | прекратить отслеживание |
| `/list` | список отслеживаемых товаров |
| `/history 12345678` | история цен из SQLite |
| `/stats` | количество товаров в базе, размер кэша, время до следующей проверки |
| `/diag` | диагностика: реальный запрос к API WB (для анализа антибот-защиты) |
| `/cleanup` | удаление устаревшей истории цен (хранится 30 дней) |

## Обоснование использования curl_cffi и демо-режима

Публичный API карточек Wildberries (`card.wb.ru`) не документирован и защищён от автоматизированных запросов. При обращении с обычного домашнего IP-адреса сервер возвращает ошибку 403 или пустой массив. Первоначальная реализация на `httpx` не обеспечивала доступа к API. Переход на `curl_cffi` с имитацией отпечатка браузера Chrome устранил проблему частично: ограничения применяются также по IP-адресу. В связи с этим:

- HTTP-клиент по умолчанию — `curl_cffi` (имитация Chrome);
- предусмотрена переменная `WB_PROXY` для проксирования через IP-адрес, не ограниченный антиботом;
- команда `/diag` позволяет определить, какой именно ответ вернул API;
- реализован демо-режим (`WB_DEMO_MODE=1`): бот обращается к сети только для проверки токена, цены формируются локально. Полный функционал работает без запросов к WB.


## Запуск

```bash
python -m venv .venv
pip install -r requirements.txt
export WB_BOT_TOKEN=123456:ABC...   # токен от @BotFather
export WB_DEMO_MODE=1               # 0 — реальный API WB
python bot.py
```

На Windows проще: `start.bat` самостоятельно читает `TG_TOKEN` из корневого `.env`, включает демо-режим и запускает бота из `.venv`.

Все настройки описаны в `.env.example`: интервал проверки (по ТЗ раз в сутки = 1440 минут), кулдаун уведомлений (6 часов), срок хранения истории цен, идентификатор администратора для `/cleanup`.

## Структура проекта

```
bot.py          — команды, планировщик проверок, рассылка уведомлений

tests/          — 12 тестов (парсинг ответа WB, кулдаун, БД, извлечение артикула, fallback цены, очистка карточек)
```

## Технические особенности

1. **Ошибка 403 при стандартных запросах к WB.** Доступ определяется отпечатком TLS и протоколом HTTP/2. Решение — `curl_cffi` с имитацией Chrome.
2. **Эмодзи в Windows-консоли** приводили к `UnicodeEncodeError` (кодировка cp1251). Решение — `PYTHONIOENCODING=utf-8`, зафиксировано в `start.bat`.
3. **Неограниченный рост базы данных** — каждая проверка создавала новые записи. Добавлен индекс на `(articul, checked_at)`, плановая очистка записей старше N дней, удаление карточек без подписок и команда `/cleanup`.

## Планы развития

- построение графика цены по истории вместо списка значений;
- сравнение цен нескольких артикулов в одном сообщении.
